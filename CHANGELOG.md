# Changelog — pagos-svc

Todos los cambios relevantes del microservicio se registran en este archivo.

## [1.0.0] - 2026

- Versión inicial del microservicio de pagos.
- API REST para registrar, listar y eliminar pagos.
- Página de presentación con accesos a Swagger UI y consola H2.
- Pruebas automatizadas y verificación de cobertura con JaCoCo.
- Workflow básico de integración continua con GitHub Actions.
